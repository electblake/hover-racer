## [Unreleased]

### Added

- Standalone browser hover racer with a canyon course, native WebGL 2 rendering,
  embedded geometry and audio, and no installation or build step.
- Keyboard and standard-layout gamepad driving controls, including dual-stick
  steering, throttle, air braking, sharp turns, and reset.
- Controller connection and input inspection menu with controller selection,
  stick positions, trigger levels, and button feedback.
- Fixed-step hover physics, barriers, recovery, chase camera effects, and wind
  audio.
- In-game source parity report and regression tests for driving, course
  geometry, collision, controls, camera effects, and audio data.
