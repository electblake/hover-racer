Reference date: **2026-10-25**, America/Toronto. Product: **Star Wars: Galactic Racer**. Exact game build and database revision: not supplied by the captured pages. UTC capture timestamps fall on October 26; the local reference date remains October 25.

## Scope and source authority

All six requested examples are Landspeeders. Their common structure supports generalizing a Landspeeder body assembly system, but does not establish the slots or interchange rules of bikes, skim speeders, or podracers.

The [official StarWars.com vehicle guide](www.starwars.com/news/star-wars-galactic-racer-vehicle-guide.md) establishes the four vehicle classes and the stable, drifting Landspeeder identity. Detailed build sheets, prices, presets, and upgrade tracks below come from the independently maintained Games Lantern database. No game runtime was inspected.

## Generalized reference model — design inference

The following is a proposed vocabulary for future Hover Racer design, not Galactic Racer's internal schema or an implementation commitment:

| Entity | Information to retain |
| --- | --- |
| Chassis definition | Class, root asset, explicit slot identities and attachment transforms |
| Body part definition | Stable part ID, source kit, slot identity, asset reference, explicitly supported chassis |
| Kit definition | Name, manufacturer, six stock part assignments, kit acquisition and price |
| Build preset | Chassis, explicit part ID for each slot, livery, mask |
| Appearance definition | Livery/mask identity and separately authored material data |
| Unlock record | Acquisition condition and separately recorded kit/part cost |
| Performance configuration | Class maneuver and upgrade levels, separate from body composition |

A named vehicle can be represented as a stock preset over a shared chassis. A custom build replaces explicitly selected slot assignments. A reusable asset pipeline would author matching attachment coordinates for compatible modules and preserve separate left/right identities. These coordinates would have to be authored for Hover Racer; they cannot be recovered from the text references.

For a concrete conceptual example, a Landspeeder build could retain ARZ 41 bodywork and select Dre'shi engine modules. This illustrates the proposed schema only: the captured preset summaries do not verify that exact slot combination.
