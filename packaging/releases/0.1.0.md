First Windows release of Hover Racer.

- Four racing maps: Test Canyon, Long Canyon, Venus Aureate Sea, and Jupiter Ringrunner, plus the Physics Lab.
- Live map-selection demos, reactive liquid and rain, Jupiter gravity and scenic moons.
- Rigid-body hover racing, boosts, airbrakes, resource HUD, controller setup, and cosmetic vehicle garage.

Download **Windows-Portable.zip**, extract every file, and run `HoverRacer.exe`, or use **Windows-Setup.exe** for a per-user installation. Requires Windows x64 and a Direct3D 12 capable GPU. The executables are unsigned.

SHA-256 checksums are supplied in `SHA256SUMS.txt`.

Validation: 101 automated tests and 24,244 assertions passed. The exported executable passed headless and Direct3D 12 startup smoke tests outside the source tree. Installer compilation succeeded. Clean-VM installation, upgrade, and uninstall testing was not performed because no disposable Windows environment was available; this release is published with that limitation explicitly accepted.
