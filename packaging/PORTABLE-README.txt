Hover Racer for Windows x64

Extract the entire ZIP to a writable folder and run HoverRacer.exe.
Keep the graphics libraries beside the EXE. No installation is required.
Requires a Direct3D 12 capable GPU and current graphics drivers.

W: throttle; S: brake; A/D: steer; Shift: afterburner; Ctrl: ramjet;
Space: airbrake; E: pulse; R: reset; Escape: menu.
Controller bindings and vehicle cosmetics are available from the menu.

Settings are stored in %APPDATA%\Godot\app_userdata\Hover Racer.
The installer and uninstaller preserve these settings.
